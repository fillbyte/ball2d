# Contributing

Use issues for reproducible SDK defects, API proposals and documentation fixes.
Include a minimal example, SDK version, Node.js version and operating system;
remove secrets and personal data. Do not upload private game implementation code.

Pull requests may improve documentation, examples and distribution checks. Runtime
changes are developed and verified in the private implementation repository and
exported as reviewed artifacts. Do not edit bundled JavaScript or WASM manually.

Use [the setup guide](docs/DEVELOPMENT.md). Run the package, documentation and
format checks and inspect the publish archive locally.
GitHub Actions is permanently disabled; do not add or enable workflows.
Contributions do not change the proprietary SDK license or grant access to the
private implementation.
